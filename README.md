# Sahil Khan — Portfolio

[Live site](https://sahilkhan.dev)

## Development

Run `npm ci` then `npm run dev`.

## Checks

Run `npm run lint`, `npx tsc --noEmit`, and `npm run build`. Use `npm start` for a production preview.

GITHUB_TOKEN is optional and server-only. Without it, activity uses cached public contribution data with an unavailable-state fallback.

Resume instructions: `resume/README.md`.
